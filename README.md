# Dezire Clinic — Frontend Demo

A React + Vite + Bootstrap frontend concept for Dezire Clinic Bangalore.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Important demo notes
- This is a frontend-only demo. It does not include Django, a database, or a backend.
- The consultation form opens the visitor's email application with a prefilled enquiry. Connect a secure form service or clinic backend before using it for real patient enquiries.
- Clinic address, doctor credentials, testimonials, social links and clinical claims are intentionally not invented. Replace placeholders with clinic-approved information.
- Treatment content is general information, not medical advice. Visitors should consult a qualified clinician for individual assessment.
